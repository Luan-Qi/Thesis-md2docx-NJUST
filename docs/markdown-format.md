## 1. 五分钟上手

假设你已经装好环境（见 [README 快速开始](../README.md#快速开始)）。

> 本文示例统一写成 `python md2docx.py ...`——它**不需要先安装**，在仓库根目录直接就能跑。
> 若你已 `python -m pip install -e .` 并激活了环境，把 `python md2docx.py` 换成 `md2docx` 即可。

```bash
# ① 建一个自己的论文目录
mkdir my-thesis && cd my-thesis
mkdir img

# ② 复制模板
cp /path/to/Thesis-md2docx-NJUST/example/thesis-template.md thesis.md

# ③ 用任意编辑器打开 thesis.md，按模板填内容
#    图片放进 img/，正文里用相对路径引用

# ④ 检查环境
python md2docx.py check

# ⑤ 生成 DOCX
python md2docx.py thesis.md --out output

# ⑥ 刷新目录页码（需要 Microsoft Word）
python md2docx.py refresh-fields output/thesis.docx

# ⑦ 导出 PDF 和分页图，用来检查版式
python md2docx.py thesis.md --pdf --pages --out output --backend word
```

产物：

```text
my-thesis/
├── thesis.md            ← 你的源稿
├── img/                 ← 图片
└── output/
    ├── thesis.docx      ← 提交用
    ├── thesis.pdf       ← 版式检查用
    └── pages/           ← PDF 逐页图片
```

**最重要的一条规则**：正文必须从第一个**带编号的一级标题**（`# 1 绪论`）开始。
在它之前的所有 `##` 二级标题都会被当作前置页处理。

## 2. 文件与目录约定

| 位置 | 内容 | 是否提交 |
| --- | --- | --- |
| `thesis.md` | Markdown 源稿，唯一的手写文件 | ✅ 用 Git 管理 |
| `img/` | 图片，正文用相对路径引用 | ✅ |
| `output/` | 生成物，可随时删除重建 | ❌ |

- 图片路径**必须用相对路径**（如 `img/pipeline.png`）。绝对路径在换机器后会失效。
- 源稿和图片放在外层，DOCX/PDF 放进 `output/`，不要混在一起。

## 3. 完整模板

仓库里有一份可直接复制的新论文骨架：

```text
example/thesis-template.md
```

它已经包含封面字段、声明、中英文摘要、目录、五章正文、一个表格、一张图、一个公式、
致谢、参考文献与附录。把内容换成自己的即可。

模板里带 `>` 引用块的「说明」段落只是给你看的注释，**导出前删掉**（否则它们会作为正文输出）。
引用块本身是支持的语法，但不要把说明文字留在正式论文里。

下面是模板的骨架，方便你对照：

## 4. 前置部分怎么写

### 4.1 文档标题（文件最上面的第一个 `#`）

模板第一行的 `# 论文题目第一行` 有两个作用：

1. 作为整篇文档的标题；
2. 如果 `## 封面信息` 里没写 `论文题目`，就用它兜底。

它**不参与章节编号**，所以必须写在 `# 1 绪论` 之前。

### 4.2 `## 封面信息`

用 `键：值` 的形式逐行写，中英文冒号都行。字段一览：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `论文题目` | 建议填 | 可写两行；不填则用文档标题兜底 |
| `分类号` | 可留空 | 学校要求填时按《国际十进分类法》填 |
| `密级` | 可留空 | 填了要以 `★` 标注并注明保密期限，否则留空 |
| `UDC` | 可留空 | 同上 |
| `作者姓名` | 必填 | 匿名送审写 `***` |
| `导师姓名` | 必填 | 匿名送审写 `***` |
| `导师职称` | 建议填 | 显示在导师姓名下方同一列 |
| `学位类别` | 必填 | 学术硕士填 `工学硕士` |
| `学科名称` | 必填 | 学术硕士用这个字段名 |
| `研究方向` | 必填 | |
| `论文提交时间` | 必填 | 如 `2026 年 1 月` |

留空的字段会在封面上打印空白下划线，方便打印后手填。

### 4.3 `## 声明`

```markdown
## 声明
研究生签名：
签字日期：
```

- **声明正文不要写在这里**。规范要求两段声明原文（「声明」与「学位论文使用授权声明」，
  见学校附件 2.5）不得改动，导出器会把它们原样写入，并且排在同一页的上、下两部分。
- 这里只填签名与日期。留空 = 打印空白下划线；也可以放电子签名图片：
  `研究生签名：![电子签名](img/signature.png)`

### 4.4 `## 摘要` 与 `## ABSTRACT`

```markdown
## 摘要
中文摘要正文，400—600 字。

关键词：关键词1，关键词2，关键词3

---

## ABSTRACT
English abstract.

Key word: keyword one, keyword two
```

- 中文用 `关键词：`，英文用 `Key word: `（导出器认这两个前缀）。
- 关键词之间用分号或逗号都行，**导出时统一改成逗号**。
- 导出器会在摘要末段与关键词行之间自动插入 2 个空白段落，你不用手写空行。
- 这两个标题都是**不编号的一级标题**，会自动出现在目录里，但不会自动产生分页——靠 `---` 分页。

### 4.5 `## 目录`

```markdown
## 目录
导出器会在此处写入 Word 目录域。
```

小节里的文字会被忽略。导出器会写入 Word 目录域，并生成与标题对应的书签和内部跳转。

目录页码的说明见 [8. 生成与检查](#8-生成与检查)。

## 5. 正文怎么写

### 5.1 正文起点

正文从**第一个以数字开头的一级标题**开始：

```markdown
# 1 绪论
```

`# 1 绪论` 之前的 `##` 标题全部属于前置页。这一点搞错的话，前面写的内容会被当成前置页丢掉。

### 5.2 标题层级

```markdown
# 1 绪论                 ← 一级（章）
## 1.1 研究背景           ← 二级（条）
### 1.1.1 三级标题示例     ← 三级（款）
#### 1.1.1.1 四级标题示例   ← 四级（项）
```

| 层级 | 写法 | 进目录 | 生成后字号 |
| --- | --- | --- | --- |
| 一级 | `# 1 绪论` | ✅ | 小三号加粗宋体，居左 |
| 二级 | `## 1.1 研究背景` | ✅ | 四号加粗宋体，居左 |
| 三级 | `### 1.1.1 示例` | ✅ | 小四号加粗宋体，居左 |
| 四级 | `#### 1.1.1.1 示例` | ❌ | 小四号宋体 |

- 编号用 Word 原生多级列表生成，**Markdown 里必须把编号写出来**（导出时会被去掉后交给 Word 重排）。
- 章号要与 `# N 标题` 的 N 一致，因为公式、图、表都按章号编号。
- **正文每一章不强制另页**；只有 `# 致谢`、`# 参考文献`、`# 附录` 以及独立的 `# 结论` 会另页开始。

### 5.3 段落

直接写即可。软换行会合并成同一段，空行结束当前段落。

需要在一个段落内强制换行时，行末留两个空格或写一个反斜杠 `\`。普通正文不建议这么写。

### 5.4 图片

```markdown
![图的说明文字](img/figure-3-1.png)

图3.1 实验结果总览
```

- 图题**单独成行，写在图片下方**。
- 图号按章编排：`图3.1`（第 3 章第 1 张图）；附录里是 `图A1`。
- 图题与图内文字为五号宋体，西文 Times New Roman。
- 图片默认居中，宽度按图片的 DPI 和页面宽度自动推导，通常不需要手写尺寸。
- 需要精确控制尺寸或复刻模板时，可追加属性：

  ```markdown
  ![说明](img/figure.png){width_emu=4942840 height_emu=2432685}
  ```

  `width_emu` / `height_emu` 是 Word 的 EMU 单位；只写一个时另一个按原比例推算。

### 5.5 并排图

```markdown
:::figure-row
![方法 A](img/method-a.png)
![方法 B](img/method-b.png)
:::

图3.2 不同方法的可视化对比
```

建议只放两张，且先把两张图裁成相近的宽高比。

### 5.6 表格

```markdown
表3.1 实验参数设置

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 学习率 | 0.001 | 优化器初始学习率 |
| 批大小 | 64 | 每轮训练样本数 |
```

- 表题**单独成行，写在表格上方**。
- 表号按章编排：`表3.1`；附录里是 `表A1`。
- 表题与表内文字为五号宋体，数字与西文 Times New Roman。
- 表格默认为三线表（上下线 1.5 磅、无内线），这是学校范例的做法。

### 5.7 长表与续表

在表题和表格之间插入拆分标记：

```markdown
表3.2 长表结果

<!-- thesis-table-split: 8, 10 -->

| 指标 | 实验1 | 实验2 |
| --- | --- | --- |
| ... | ... | ... |
```

`8, 10` 表示第一段保留 8 行数据、第二段 10 行，其余作为最后一段。每段续表都会重复表头
并补 `（续）` 题注。数字按**数据行**计数，不含表头行。

### 5.8 合并表头等复杂表格（`::: table`）

学校范例里有合并表头、固定列宽或特殊线宽的表格，普通管道表表达不了，用扩展语法：

```markdown
表3.3 方弯管内流动最大速度比较

::: table {width=8529 width_type=dxa widths=2251,1546,1548,1547,1637 top_border=12 bottom_border=12 header_rows=2 header_bold=false}
| 项目 {rowspan=2} | 层流 {colspan=2} | 紊流 {colspan=2} |
| 0°截面 | 90°截面 | 0°截面 | 90°截面 |
| 理论值 | 0.04 | 0.03 | 1.30 | 1.25 |
:::
```

常用参数与单元格属性见 [docs/usage.md 的表格一节](usage.md#表格)。

### 5.9 公式

行内公式用单个 `$`：

```markdown
其中 $s_t$ 表示状态，$a_t$ 表示动作。
```

块公式用独立的 `$$`（独占一行）：

```markdown
$$
J(\theta)=\mathbb{E}_{\tau \sim \pi_\theta}\left[\sum_{t=0}^{T}\gamma^t r_t\right]
$$
```

- 块公式会**自动按章编号**，格式 `（2.3）`（第 2 章第 3 式）；附录里是 `（A.1）`。
- 正文引用写成 `式（2.3）`。
- 装了公式依赖（`npm install --prefix thesis_md2docx/math/latex2omml_node`）时输出为
  Word 原生可编辑公式；否则原样输出 LaTeX 文本。

### 5.10 引用与参考文献

正文引用：

```markdown
已有研究表明该方法有效[1-2]，也有工作给出了不同结论[1，3-4]。
```

导出器会生成上标引用和到文末条目的内部跳转。参考文献列表写在 `# 参考文献` 下：

```markdown
# 参考文献

[1] 作者. 文献题名[文献类型]. 出版信息.
[2] Author A, Author B. Title[J]. Journal, 2020, 12(3): 45-56.
```

编号必须与正文引用一一对应。

## 6. 后置部分怎么写

顺序固定为 **结论 → 致谢 → 参考文献 → 附录**（规范 3.1），且各自另页开始。

### 6.1 结论

两种写法都支持：

```markdown
# 5 结论与展望     ← 编号章，与其他章一样，不强制另页
```

```markdown
# 结论            ← 不编号，强制另页
```

按你们课题组习惯选一种即可，不要两种都写（规范 3.2 明确不另加重复结论）。

### 6.2 致谢

```markdown
# 致谢
致谢正文。
```

标题会自动显示为「致  谢」，不编号、另页开始。

### 6.3 参考文献

见 [5.10](#510-引用与参考文献)。条目为小四号宋体、固定值 20 磅行距。

### 6.4 附录

```markdown
# 附录

## 附录A 补充材料
附录正文。
```

- 写成 `## 附录 A 补充材料` 也可以，导出时会规范化为 `附录A 补充材料`。
- 附录内的图表编号为 `图A1`、`表A1`（字母 + 序号，无点号）；写成 `图 A-1` 会被自动规范化。
- 附录公式编号为 `（A.1）`。

## 7. 由导出器固定、你不需要写的格式

以下格式由 profile 按学校规范固定，**不要在 Markdown 里试图控制**：

| 项目 | 生成结果 |
| --- | --- |
| 纸张与页边距 | A4；上 30mm、下 24mm、左右各 25mm；页眉/页脚距边界 20mm |
| 页边距方式 | 对称页边距 |
| 正文 | 小四号宋体，首行缩进 2 字符，固定值 20 磅行距，两端对齐 |
| 一级/二级/三级标题 | 小三 / 四号 / 小四，加粗宋体，居左，段前后 18 / 12 / 6 磅 |
| 摘要 / Abstract / 目录 / 致谢 / 参考文献 / 附录标题 | 三号加粗宋体，居中，段前后 18 磅 |
| 图题、表题、表内文字 | 五号宋体，西文 Times New Roman |
| 页码 | 前置部分罗马数字（I、II…），正文起阿拉伯数字（1、2…），位于页面外侧 |
| 页眉 | 奇数页「硕士学位论文 + 论文题目」，偶数页「章节名 + 硕士学位论文」，小五号宋体 |
| 分节 | 封面+声明隐藏页眉页码；摘要起显示页眉与罗马页码；正文起改为阿拉伯页码 |
| 封面 | 校徽、学位类别大字、题名、作者、导师、学位类别/学科名称/研究方向/提交时间 |

封面字段的位置、校徽尺寸等由 `thesis_md2docx/profiles/njust_master_thesis/constants.py`
控制；确需调整时改那一处，不要在 Markdown 里绕。

## 8. 生成与检查

### 8.1 命令

```bash
# 只生成 DOCX
python md2docx.py thesis.md --out output

# 生成 DOCX + PDF + 分页图
python md2docx.py thesis.md --pdf --pages --out output --backend word

# 刷新目录页码（需要 Microsoft Word）
python md2docx.py refresh-fields output/thesis.docx

# 对照学校范例做结构与像素审计
python md2docx.py compare-docx format_requirements/基于雷视融合的不良天气船舶检测研究_anno.docx \
  output/thesis.docx --out output/audit.md
python md2docx.py compare-pdf format_requirements/范例.pdf output/thesis.pdf \
  --out output/pdf-audit.md --diff-dir output/pdf-diff
```

### 8.2 关于目录页码

生成 DOCX 时目录里的页码是**占位值**——真实页码要等 Word 分页后才知道。所以：

- **导出 PDF 时不需要额外操作**：Word 后端会在导出前自动更新域，PDF 里的目录页码是对的。
- **提交用的 DOCX 需要刷新一次**：

  ```bash
  python md2docx.py refresh-fields output/thesis.docx
  ```

  或者用 Word/WPS 打开，`Ctrl+A` 后按 `F9`（右键目录 → 更新域 → 更新整个目录），再保存。

刷新后的文档既没有待更新域，也不引用任何外部文件，以后再打开不会弹任何提示。

### 8.3 提交前检查清单

- [ ] 正文确实从 `# 1 绪论` 开始，前面没有混入正文内容
- [ ] 章号与 `# N` 一致，图表公式编号与所在章一致
- [ ] 所有图片路径都是相对路径，且在 Word 里都显示出来了（没有占位文本）
- [ ] 图题在图下方、表题在表上方，且各自单独成行
- [ ] 正文引用编号与参考文献条目一一对应
- [ ] 目录页码已刷新，且与正文实际页码一致
- [ ] 附录图表编号为 `图A1` / `表A1` 形式
- [ ] 模板里的 `>` 说明段落已删除
- [ ] 在 Word/WPS 里通读一遍：分页、孤行、表格跨页、公式显示

## 9. 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 前面写的内容不见了 | 正文起点识别失败，被当成前置页 | 确保有 `# 1 绪论` 这样以数字开头的一级标题 |
| 章节编号不对 | `# N` 的 N 与章号不一致 | 统一编号；图表公式都按 N 编号 |
| 图题被当成正文 | 图题和图片写在同一行 | 图题单独成行 |
| 目录里出现四级标题 | 四级标题本来就不进目录 | 正常现象；如需进目录先升到三级 |
| 公式是 LaTeX 文本而不是公式 | 未安装公式依赖 | `npm install --prefix thesis_md2docx/math/latex2omml_node` |
| 打开 DOCX 提示「域可能引用了其他文件」 | 不是本工具生成的（或用了旧版） | 用当前版本重新生成；本文档第 8.2 节说明了成因 |
| 封面字段换行错乱 | 字段值过长 | 缩短字段值，或按需调整 `constants.py` 中的制表位 |
| 目录后多出一页（只有页眉页码） | Word 在重启页码的分节处插入一页，让阿拉伯页码 1 落在奇数页 | 见 [AGENT.md 坑 6](../AGENT.md)；成因与目录长度无关 |
| `md2docx`: command not found | 未安装或未激活环境 | 在仓库根目录用 `python md2docx.py ...`，或 `pip install -e .` |
